# Power BI — Summer Olympic Games

---

## *VERSIÓN EN ESPAÑOL*

### Contexto

Proyecto de análisis y visualización sobre los **Juegos Olímpicos de Verano**. El objetivo era explorar el histórico de participación y medallero para construir un dashboard interactivo que respondiese preguntas sobre países, deportes y evolución a lo largo del tiempo.

### Datos

Dataset histórico de los Juegos Olímpicos de Verano, con variables de país, deporte, disciplina, medallas, edición y atletas.

### Análisis

- Preparación y exploración de datos, con un notebook de apoyo en Python.
- Modelado de datos en Power BI.
- Construcción de un dashboard interactivo con medallero, evolución temporal y comparativas por país y deporte.

### Resultado

Dashboard interactivo (`.pbix`, con versión exportada en `.pdf`) que ofrece vistas de medallero, tendencias históricas y rendimiento por país y disciplina.

### Conclusión

Un caso completo de inteligencia de negocio, de los datos crudos al dashboard, que convierte un histórico extenso en una herramienta visual para explorar el rendimiento olímpico.

**Stack:** Power BI, DAX, Power Query, Python

### Archivos

- `Summer Olympic Games Dashboard.pbix` — dashboard de Power BI.
- `Summer Olympic Games Dashboard.pdf` — versión exportada.
- `Summer_Olympic_Games_Analysis.ipynb` — notebook de preparación y análisis.
- `olympics_dataset.csv`, `summer_olympic_dataset_1986_2024.csv` — datasets.

## *ENGLISH VERSION*

### Context

An analysis and visualization project on the **Summer Olympic Games**. The goal was to explore the historical participation and medal data to build an interactive dashboard answering questions about countries, sports and evolution over time.

### Data

A historical Summer Olympics dataset, with variables for country, sport, discipline, medals, edition and athletes.

### Analysis

- Data preparation and exploration, with a supporting Python notebook.
- Data modeling in Power BI.
- An interactive dashboard with medal table, historical trends and country/sport comparisons.

### Result

An interactive dashboard (`.pbix`, with an exported `.pdf` version) providing medal-table, historical-trend and country/discipline performance views.

### Conclusion

A complete business-intelligence case, from raw data to dashboard, turning an extensive historical dataset into a visual tool to explore Olympic performance.

**Stack:** Power BI, DAX, Power Query, Python

### Files

- `Summer Olympic Games Dashboard.pbix` — Power BI dashboard.
- `Summer Olympic Games Dashboard.pdf` — exported version.
- `Summer_Olympic_Games_Analysis.ipynb` — preparation and analysis notebook.
- `olympics_dataset.csv`, `summer_olympic_dataset_1986_2024.csv` — datasets.
